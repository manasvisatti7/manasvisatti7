## 🚀 Featured Project — AirGuard AI

### Smart Compressed Air System Health Monitoring & Energy Optimization Platform

**AirGuard AI** is an **Industry 4.0/5.0 retrofit IoT and cloud analytics platform** designed to continuously monitor, validate, and optimize compressed-air infrastructure in manufacturing MSMEs.

The project was developed as a **proposal for the MSME Idea Hackathon 6.0 grant scheme**, with a proposed total budget of **₹15 Lakhs**.

The system combines **edge sensing, real-time telemetry, machine-specific baselining, anomaly detection, health scoring, and financial waste estimation** to help manufacturing units move from reactive maintenance toward condition-based monitoring and energy optimization.

### 📌 Project Details

* **Domain:** Industry 4.0/5.0 • IoT • Edge Computing • Smart Manufacturing
* **Target Users:** Compressor-dependent MSMEs
